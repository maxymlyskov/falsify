# ADR-0007 — The plugin is called falsify

**Status:** accepted · 2026-09-07

## Context

The first name, burden (as in burden of proof), read as a complaint rather than a method. Descriptive
compounds (probe-first, proofgate) read as feature lists and are how nobody remembers a tool. The tools
people do remember borrow one word from a domain where the metaphor already carries the meaning.

## Decision

`falsify`. Popper's criterion: a claim counts only if it could have failed and did not. That is the probe
(a test that must fail first, with the reported value), the QA agent (told to falsify the design's
reasoning), and mutation testing (tests that could fail). The name states the method in one word a senior
reader recognises without explanation.

Rejected: touchstone (the best metaphor; touchstonejs holds the name), litmus (litmuschaos), inquest
(a security company), assay (fits the graded score; no strong reason over falsify), proofmark (needs a
sentence of explanation), ordeal (also means a painful experience), task (13k-star collision, and
`/task:task`).

## Consequences

Namespace `/falsify:task`, `/falsify:setup`, `/falsify:grilling`. Config `.claude/falsify.config.json`.
Repository `maxymlyskov/falsify`. The word is a verb; the README uses it as a name and never conjugates it.
